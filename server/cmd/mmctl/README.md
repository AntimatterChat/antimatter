# amctl

`amctl` (Mattermost's `mmctl`) is a remote CLI tool that lets you manage your Antimatter instance from the terminal.

Its commands live in this directory; the binary is built from `../amctl` (`make mmctl-build` writes `bin/amctl`). Upstream documentation is available in [the Mattermost documentation](https://docs.mattermost.com/manage/mmctl-command-line-tool.html).
