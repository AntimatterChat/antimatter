.. _amctl:

amctl
-----

Remote client for the Open Source, self-hosted Slack-alternative

Synopsis
~~~~~~~~


Antimatter, based on Mattermost, offers workplace messaging across web, PC and phones with archiving, search and integration with your existing systems. Upstream documentation is available at https://docs.mattermost.com

Options
~~~~~~~

::

      --config string                path to the configuration file (default "$XDG_CONFIG_HOME/amctl/config")
      --disable-pager                disables paged output
  -h, --help                         help for amctl
      --insecure-sha1-intermediate   allows to use insecure TLS protocols, such as SHA-1
      --insecure-tls-version         allows to use TLS versions 1.0 and 1.1
      --json                         the output format will be in json format
      --local                        allows communicating with the server through a unix socket
      --quiet                        prevent amctl to generate output for the commands
      --strict                       will only run commands if the amctl version matches the server one
      --suppress-warnings            disables printing warning messages
